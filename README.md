# EcoHome | Evaluación de la APK

Esta rama reúne las instrucciones para **descargar la APK de evaluación y recibir comentarios** del proyecto académico EcoHome.

EcoHome es una aplicación Flutter de casa inteligente simulada para Android.

## Descargar la aplicación

**Estado: APK disponible para evaluación — v1.0.0.**

### [Descargar app-release.apk](https://github.com/BryanGS23/EcoHome/releases/download/v1.0.0/app-release.apk)

También puedes visitar **[Releases (descargas)](https://github.com/BryanGS23/EcoHome/releases)** y consultar la [versión v1.0.0](https://github.com/BryanGS23/EcoHome/releases/tag/v1.0.0). El archivo se encuentra en la sección **Assets** de la publicación.

### Instalación en Android

1. Descarga **app-release.apk** desde el enlace anterior o desde Releases.
2. Abre el archivo en tu dispositivo Android.
3. Si Android solicita permiso para instalar aplicaciones desde esa fuente, autorízalo solo si confías en el archivo descargado de este repositorio.
4. Completa la instalación y abre **EcoHome**.

La aplicación está destinada a **Android**. Necesita conexión a Internet para las funciones que utilizan Firebase.

## Qué puedes evaluar

- Inicio de sesión, registro y recuperación de contraseña.
- Navegación y claridad de los menús.
- Resumen del hogar y organización por áreas.
- Dispositivos y escenas simuladas.
- Energía simulada, actividad y alertas.
- Perfil y experiencia general de uso.

**Alcance:** es una versión de evaluación académica. EcoHome no controla hardware real y el consumo energético es simulado. Algunas funciones o integraciones pueden estar incompletas o no estar disponibles en la APK evaluada.
